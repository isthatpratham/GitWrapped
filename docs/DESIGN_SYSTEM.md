# GitWrapped Design System

## Design Philosophy

GitWrapped should feel premium, calm, editorial, and handcrafted.

It should never resemble a dashboard or an AI-generated SaaS landing page.

---

# Theme

Dark mode only.

There will never be a light theme.

---

# Typography

Primary Font

Montserrat

Rules

* Use Montserrat everywhere.
* Do not mix fonts.
* Use monospace only for code snippets.

---

# Visual Principles

* Large typography
* Generous whitespace
* One message per screen
* Minimal decoration
* Purposeful motion
* Consistent spacing

---

# Design Inspirations

* Apple
* Linear
* Vercel
* Arc Browser
* Raycast
* Stripe

---

# Avoid

* Dashboard aesthetics
* Bento grids
* Excessive glassmorphism
* Neon gradients
* Floating blobs
* Random icon walls
* Generic Tailwind layouts

---

# Shadows

Very subtle.

Never use large blurry shadows.

---

# Motion

Allowed

* Fade
* Scale
* Opacity
* Slide
* Blur
* Smooth spring

Avoid

* Bounce
* Spin
* Flip
* Flashing
* Confetti

---

# Cards

Only use cards when they improve information hierarchy.

Prefer whitespace over unnecessary containers.

---

# Charts

* Minimal
* Thin strokes
* Smooth animations
* Limited colors
* No unnecessary legends

---

# Icons

Lucide only.

---

# Components

Every component must:

* Have a single responsibility.
* Be reusable.
* Be composable.
* Support dark mode.

---

# Accessibility

* Semantic HTML
* Keyboard navigation
* Proper labels
* WCAG-friendly contrast

---

# Final Rule

If removing an element makes the interface stronger, remove it.
