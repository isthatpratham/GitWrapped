# GitWrapped

> Your year in code, beautifully wrapped.

GitWrapped transforms a developer's public GitHub activity into a beautiful, story-driven annual recap.

Instead of overwhelming users with dashboards and endless statistics, GitWrapped presents a cinematic experience that highlights coding habits, milestones, achievements, and insights through immersive storytelling.

---

## Vision

GitWrapped is built around one simple idea:

> Every developer has a story. GitWrapped helps tell it.

The goal is not to build another GitHub analytics website.

The goal is to create an experience people genuinely enjoy sharing.

## Design Principles

GitWrapped follows a strict design philosophy.

- Dark mode only
- Montserrat as the only application font
- Storytelling over dashboards
- Clean, premium interfaces
- Motion with purpose
- Minimal visual noise
- No unnecessary UI decoration

Every screen should feel intentional.

## Development

Clone the repository.

```bash
git clone https://github.com/<your-username>/gitwrapped.git

cd gitwrapped
```

Install dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```
